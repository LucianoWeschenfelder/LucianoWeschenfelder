## 🚀 Projeto em destaque

### Controle de Empenhos

Sistema para acompanhar a execução de empenhos na logística, do cadastro da Nota
de Empenho até o recebimento do material com nota fiscal.

Nasceu de uma necessidade real: um empenho não é consumido de uma vez. O material
chega em partes, e controlar isso em planilha gera erro — pedir mais do que existe
de saldo, ou perder de vista o que foi pedido e não chegou.

**A regra que dá sentido ao sistema:** fazer um pedido **não** diminui o saldo do
empenho. Só a nota fiscal diminui. Enquanto o material não entrou fisicamente, o
saldo continua lá — e o que foi pedido aparece à parte, para não pedir duas vezes
a mesma coisa.

O que ele faz:

| Recurso | Descrição |
|---|---|
| 📄 Leitura de documento | Extrai os dados do PDF da Nota de Empenho e preenche o cadastro |
| 🧮 Três quantidades | Controla empenhado, pedido e saldo separadamente para cada item |
| 📦 Entrega flexível | Aceita entrega parcial, ou quantidade maior que a pedida |
| 🧾 Nota fiscal | Permite corrigir e excluir NF, devolvendo o saldo ao empenho |
| ✂️ Anulação | Anula item parcial ou totalmente, respeitando o que já foi entregue |
| ⏰ Alerta de atraso | Sinaliza de forma graduada, conforme os dias de espera |
| 🔐 Acesso por perfil | Separa a visão por unidade e seção |

Construído em **HTML, CSS e JavaScript puros**, sem frameworks.
